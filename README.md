## 🚀 Programs Included

### 💰 ApplyDiscount.py

Implements discount calculations based on predefined conditions and pricing rules.

### 👨‍💼 EmployeeProfile.py

Manages employee information using Python classes and object-oriented concepts.

### 🏥 MedicalRecordValidator.py

Validates medical record data according to specified criteria and input rules.

### 🎬 MovieTicketCalculator.py

Calculates movie ticket prices based on user selections and ticket categories.

### 🔢 NumberPattern.py

Generates numerical patterns using loops and logical conditions.

### 📍 PinExtractor.py

Extracts and processes PIN codes from user-provided data.

### ✍️ PoemPinExtractor.py

Demonstrates text parsing techniques by extracting specific information from textual content.

### 🍽️ RestaurantBillCalculator.py

Calculates restaurant bills including item costs, taxes, and final totals.

### 🔐 TextEncryptor.py

Implements basic text encryption and transformation techniques.

### 🌦️ TravelWeatherPlanner.py

Provides travel planning assistance based on weather-related conditions.

### 📧 email_system.py

A simple email management system demonstrating class design and message handling.

### 👨‍💻 employee_management.py

Employee management application using object-oriented programming principles.

### 🎮 game_character.py

Models game characters using classes, attributes, and methods.

### 🎵 musical_instrument.py

Represents musical instruments through object-oriented design.

### 🪐 planet_class.py

Demonstrates class creation and object management using planetary data.

### 📝 practice_question.py

Contains additional Python practice exercises and programming challenges.
